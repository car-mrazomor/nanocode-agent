Quick start
All install options →

    

      

        Install
        
        
      

      

        
# Installs into ~/.nanocode. Gets Python for you if it's missing.

        
$ curl -fsSL https://raw.githubusercontent.com/car-mrazomor/nanocode-agent/master/install.sh | sh

        
# Then start it and pick a provider

        
$ nanocode

      

    

    
Also on Android (Termux). Update with /update, check with nanocode doctor, remove with nanocode uninstall.

What it does

    

      
{ }
Hackable, fully editable
The whole agent is one Python file. Read it in an afternoon, change any prompt, tool or key, and it's yours.

      
←
Asks before it acts
Reads, edits, searches and runs commands. Edits show a diff and wait for your OK — or switch to Auto. /undo reverts.

      
$
Background shells
Dev servers and watchers keep running in tmux or screen while it works and reads their output.

      
◆
Persistent memory
Global and per-project notes it always follows. Type # note to remember something.

      
◈
Skills
Drop in any SKILL.md — Claude Code skills work too. Run one with /name, or let it write its own.

      
∴
Thinking levels
/think off, low, medium or high, for every provider. Shown right under the prompt.

      
%
Reverse engineering
Optional REA tools for binaries, APKs, Electron apps, web bundles and firmware — installed for you.

      
⇅
A mouse that works
Smooth scrolling, drag to select and copy, and your message pinned on top while you read the answer.

      
↑
Costs and updates
Time, tokens and cost after every reply, /compact when context fills up, and /update when a new version is out.

    

  


  

    
Bring your own model
Switch any time →

    

      
/provider claude
Claude subscription
The plan you already pay for, through the Claude Agent SDK. No API key.

      
/provider openrouter
OpenRouter
Any model — Claude, GLM, GPT, Gemini, DeepSeek, Kimi — or the auto router. Cost shown per reply.

      
/provider ollama
Ollama
Local models on your machine. Free, private and offline.
