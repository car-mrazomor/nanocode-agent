Bring your own model

Three ways to run it.

Switch any time with /provider and /model. Same tools, same interface.

/provider claude

Claude subscription

Uses the plan you already pay for, through the Claude Agent SDK. No API key.

/provider openrouter

OpenRouter

Any model: Claude, GLM, GPT, Gemini, DeepSeek, Kimi — or the auto router. Cost shown per reply.

/provider ollama

Ollama

Local models on your machine. Free, private and offline. Small models get a lighter tool set.

Features

Small, but it does the job.

Everything a coding agent needs, in a full-screen terminal UI that stays out of your way.

←

Tools that ask first

Read, edit, search and run commands. Edits show a diff and wait for your OK — or switch to Auto. /undo reverts.

$

Background shells

Dev servers and watchers keep running in tmux or screen while the agent works and reads their output.

◆

Memory

Global and per-project notes it always follows. Type # note to remember something.

◈

Skills

Drop in any SKILL.md — Claude Code skills work too. Run one with /name, or let it learn new ones.

∴

Thinking levels

/think off, low, medium or high, for every provider. Shown right under the prompt.

▣

Costs in sight

Time, tokens and cost after every reply, context use in the status bar, /compact when it fills up.

%

Reverse engineering

Optional REA tools for binaries, APKs, Electron apps, web bundles and firmware — installed for you.

⇅

A mouse that works

Smooth scrolling, drag to select and copy, your message pinned on top while you read the answer.

↑

Stays up to date

Tells you when a new version is out. /update installs it in the background.

Get started

One line to install.

Everything goes into ~/.nanocode. No admin rights — Python is downloaded privately if you don't have it.

$ curl -fsSL https://raw.githubusercontent.com/car-mrazomor/nanocode-agent/master/install.sh | sh
nanocodestart, pick a provider
nanocode -p "…"one prompt, no UI
nanocode doctorcheck the setup

Also on Android (Termux). Update with /update, remove with nanocode uninstall.

Small enough to read.
