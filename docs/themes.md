# Themes

`/theme` lists the themes and the current colors; `/theme <name>` switches (and remembers it). You can also set `"theme"` in the config.

| Theme | Look |
|---|---|
| `opencode` | The default: OpenCode's dark theme with nanocode's blue and violet |
| `nanocode` | The older, grayer one |
| `tokyonight` | Tokyo Night: deep blue-black, blue and purple |
| `catppuccin` | Catppuccin Mocha: soft pastels on dark |
| `gruvbox` | Gruvbox dark: warm, retro |
| `nord` | Nord: arctic blue-gray |
| `dracula` | Dracula: purple and pink |
| `everforest` | Everforest: muted greens |
| `one-dark` | Atom's One Dark |
| `solarized-dark` | Solarized dark |
| `kanagawa` | Kanagawa: ink and wave blues |
| `rosepine` | Rosé Pine: muted rose and pine |
| `github-light` | A light theme, after GitHub's |

Any single color can be changed on top of a theme: `/theme accent #ff79c6`, `/theme accent default`, `/theme reset`. `/theme` lists the color names.

The light theme suits a light terminal background. Code blocks in replies keep their dark highlighting.
